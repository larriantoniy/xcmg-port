# SiteMind Validation Lab: port-tech.ru

`port-tech.ru` is the Validation Lab for SiteMind.

```text
BASELINE
↓
OBSERVATION
↓
EVIDENCE
↓
HYPOTHESIS
↓
MANUAL SEO EXPERIMENT
↓
MEASUREMENT
↓
VERDICT
↓
LEARNING
```

SiteMind is not being developed yet. First, approximately three to five real
manual SEO experiments must be completed. The future SiteMind architecture must
grow from a repeated real workflow, not from technology added for a portfolio.

Evidence comes first. Correlation does not establish causation. A valid verdict
is `INSUFFICIENT_DATA` when the available evidence cannot support a conclusion.

## Responsibilities

### SiteMind / SEO workflow

Responsible for WHAT + WHY:

- analyse evidence;
- identify opportunities;
- formulate hypotheses;
- define experiments;
- measure results;
- create verdicts;
- preserve learnings.

### Codex

Responsible for HOW:

- modify repository code;
- implement approved changes;
- run tests;
- run build;
- prepare commits / PRs when requested.

Codex must not independently treat an implementation as a successful SEO
experiment.
